# Contributing to Bookflow

Thanks for considering a contribution!

## Reporting bugs

Open an issue with:
- WordPress, WooCommerce, and PHP versions
- Steps to reproduce
- Expected vs. actual behavior

## Pull requests

1. Fork the repo and create a branch off `main`
2. Keep PRs focused — one fix or feature per PR
3. Follow the existing code style (WordPress PHP coding standards)
4. Test against a real WooCommerce store before submitting
5. Describe what changed and why in the PR description

## Development setup

Bookflow is a standard WordPress plugin — drop it into `wp-content/plugins/bookflow` on any local WordPress + WooCommerce install (e.g. Local, wp-env, or Docker) and activate it.

## Code of conduct

Be respectful and constructive. Issues or PRs that are abusive or off-topic will be closed.
